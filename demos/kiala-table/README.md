# Kiala Table — demonstração NEXORA

Website estático de demonstração para um restaurante fictício em Talatona, Luanda, Angola.

- HTML, CSS e JavaScript sem dependências.
- Mobile responsive.
- Metadados SEO, Open Graph e dados estruturados Restaurant.
- Conteúdo, contactos, pratos e localização são ilustrativos; substituir antes de qualquer utilização comercial.
- A página usa noindex/nofollow para evitar que um negócio fictício seja indexado como real.

Criado como peça de portfólio da NEXORA Marketing & IA.
