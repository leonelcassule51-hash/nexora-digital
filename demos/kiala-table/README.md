# Kiala Table — demonstração NEXORA

Website estático de demonstração para um restaurante fictício em Talatona, Luanda, Angola.

- HTML, CSS e JavaScript sem dependências de runtime.
- Layout responsivo, navegação móvel e galeria fotográfica.
- Fotografias de referência servidas a partir do Pexels; não representam pratos reais do restaurante fictício. Créditos e links para os fotógrafos estão no rodapé.
- Metadados Open Graph, Twitter Card, SEO básico e dados estruturados Restaurant.
- A página usa `noindex,nofollow` porque a marca e o restaurante são fictícios.
- Morada, contactos, preços e disponibilidade não são apresentados como dados reais.

Criado como peça de portfólio da NEXORA Marketing & IA.
